## Spring 테스트 학습

> 스프링 테스트 코드 작성을 학습하기 위한 실습 저장소
> 간단한 테스트 코드 연습과 미니 프로젝트를 포함합니다.

### 목표

- 스프링 환경에서 테스트 코드 작성에 익숙해지기
- Dummy / Stub / Fake / Mock / Spy 개념을 직접 써보며 체득

### 1. di

- 테스트 컨테이너 사용 vs 컨테이너 없이 테스트 비교
- 테스트에서 의존성 주입 방식 차이 이해
- 요구사항: 정책에 따라 할인율 계산
  - 정책1: 주문 금액이 10만원 이상이면 10% 할인해주는 서비스 (RateDiscountPolicy)
  - 정책2: 고정 금액 할인 (FixDiscountPolicy)

### 2. StudyLog

- 테스트 연습을 위한 간단한 도메인 기반 미니 프로젝트
- 사용 기술: Java, SpringBoot, JUnit 5
